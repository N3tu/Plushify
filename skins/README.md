# Plushify skin gallery

Skins added here are public. Anyone can view and download them for personal gameplay.

## Submit a skin

1. Sign in to GitHub and fork the Plushify repository.
2. In your fork, open this folder and choose **Add file → Upload files**. Add one Minecraft skin PNG with a unique name such as `username-skin.png`.
3. Open a pull request to Plushify. Include the skin’s name, whether it uses Classic or Slim arms, and any required credit.

Submit only skins you have permission to publish. A submission gives Plushify permission to host and display your PNG and let visitors download it for personal gameplay. You keep your rights to the skin. The project maintainer reviews submissions before adding them to the gallery.

If you want your skin removed from the gallery, contact [N3TU](https://github.com/N3tu) with the file link. Copies and Git history can remain after removal.
