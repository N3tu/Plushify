Privacy

Plushify is maintained by N3TU and hosted on GitHub Pages.

Skin previews and downloads

Your skin file, preview image and resource-pack ZIP are processed in your browser. Choosing a file does not send it to Plushify or GitHub. Reloading the page clears the selected skin from the creator. Downloaded files remain wherever you save them.

Website hosting

Plushify does not set cookies or run analytics. Your browser requests the page and assets from GitHub Pages. GitHub logs the IP addresses of Pages visitors for security purposes. See GitHub’s privacy statement for its handling of service data.

Public skin gallery

Sharing is optional and takes place on GitHub using your GitHub account. Submitted PNGs, GitHub usernames and pull requests are public. Accepted skins can be downloaded from the repository. Copies and commit history can remain after removal from the gallery.

Contact

Contact N3TU for questions about this creator or to request removal of a skin. Include the gallery link and avoid posting personal information publicly.
