Privacy

Plushify is maintained by N3TU and hosted on GitHub Pages.

Skin previews and downloads

Plushify reads your selected skin and generates previews and resource-pack ZIPs in your browser. Your skin is not sent to a server. Reloading the creator clears the selected skin. Downloaded files remain wherever you save them.

Website hosting

Plushify does not set cookies or run analytics. Your browser requests the page and assets from GitHub Pages. GitHub logs the IP addresses of Pages visitors for security purposes. See GitHub’s privacy statement for its handling of service data.

If you change the visual effects setting, Plushify remembers it in the current browser tab.

Contact

For questions about Plushify, contact N3TU on GitHub.
